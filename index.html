Sobre mí

Ingeniero de Sistemas con productos en producción

Estudiante de ingeniería en la Javeriana con plataformas desplegadas en producción.

He desplegado plataformas web en producción como SysteFarma, la plataforma de gestión sanitaria para droguerías colombianas, y Asistencia GABO, un sistema de asistencia escolar para 1.200 estudiantes.

Mi enfoque: productos que funcionan de verdad. Backend sólido, frontend cuidado y la mano del ingeniero que lleva un proyecto hasta el deploy.

  • HTML → React · Astro web — del cero a interfaces modernas.
  • Python · Django backend — APIs y sistemas en producción.
  • YOLOv8 · OpenCV visión — analítica por cámaras para retail.
  • PostgreSQL · Docker · CI/CD deploy — hasta el servidor real.
